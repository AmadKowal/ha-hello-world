# Hello world

A Home Assistant app that logs `Hello world!` and shows a hello page inside Home Assistant.

[![Open your Home Assistant instance and show the add app repository dialog with a specific repository URL pre-filled.](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2FAmadKowal%2Fha-hello-world)

## Add this repository

On Home Assistant OS, open **Settings → Apps → Install app**. In the top-right menu, select **Repositories**, paste this URL, and select **Add**:

```text
https://github.com/AmadKowal/ha-hello-world
```

Hello world then appears in the app store. Install it and start it. The Supervisor builds the image on the device. Open **Open Web UI** to see the page.
